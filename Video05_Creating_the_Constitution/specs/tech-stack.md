# Tech Stack

## Backend

- Language: TypeScript (server-side).
- Runtime: Node.js (LTS).
- Framework recommendation: Hono.

## Data

- Database: SQLite.
- Persistence approach: simple repository layer with clear boundaries for ailments, therapies, and appointments.

## Frontend Delivery

- Server-rendered pages with progressive enhancement where needed.
- Compatibility target: modern evergreen browsers.

## Quality

- Type safety: strict TypeScript configuration.
- Testing: unit tests for core logic and integration tests for core routes.
