# Roadmap

High-level implementation order in very small phases.

## Phase 1: Foundation

- Create baseline TypeScript server app.
- Add health check route.
- Add shared layout shell and navigation.

## Phase 2: Dashboard Skeleton

- Build agent dashboard view.
- Build staff dashboard view.
- Add placeholder widgets for ailments, therapies, and appointments.

## Phase 3: Ailments

- Define ailments data model.
- Implement create ailment flow.
- Implement ailments list and detail views.

## Phase 4: Therapies

- Define therapies data model.
- Implement therapy catalog view.
- Implement ailment-to-therapy recommendation display.

## Phase 5: Appointments

- Define appointment and availability models.
- Implement booking flow for agents.
- Implement schedule management flow for staff.

## Phase 6: Quality and UX

- Improve visual polish and accessibility.
- Add regression tests for key user journeys.
- Prepare sample data for demos.
