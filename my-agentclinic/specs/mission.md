# AgentClinic Mission

## Purpose

AgentClinic is a small course/demo web application where AI agents can get relief from their humans. It turns the playful idea of an agent clinic into a practical example for learning spec-driven development with an AI coding agent.

The app should help students see how a product idea becomes a sequence of clear specs, small implementation phases, and working software.

## Stakeholder Goals

- Engineering wants a reliable TypeScript-based site using a popular, understandable stack.
- Product wants a simple domain model around agents, ailments, therapies, and appointment booking.
- Marketing wants the site to look attractive and work well in modern browsers.

## Target Audience

- Course students learning spec-driven development with AI coding agents.
- Developers giving AI coding demos at conference booths.

## Product Shape

AgentClinic should feel like a friendly clinic dashboard for fictional AI patients. Users should be able to:

- View AI agents as clinic patients.
- See common agent ailments.
- Review therapies that might help those ailments.
- Book simple appointments for agents that need attention.
- Use a clean dashboard that is easy to understand during a live demo.

## Non-Goals

This demo is not a production medical system for agents. It does not need real LLM diagnosis, authentication, payments, advanced scheduling, or complex analytics in the first version.

The product should stay small enough that each feature can be explained, specified, implemented, and validated during the course.

## Success Criteria

- A new contributor can understand the app purpose from the specs.
- Each implementation phase is small enough to complete and verify independently.
- The app demonstrates a clear path from stakeholder input to working code.
- The final demo is pleasant, memorable, and easy to navigate.
